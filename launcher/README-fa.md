# هستهٔ اولیهٔ لانچر N.U — نسخهٔ 0.1

**وضعیت:** پیاده‌سازی آزمایشی روی شاخهٔ مستقل؛ نه خروجی نصب‌شدنی و نه تأییدشده برای انتشار.

سند مرجع یکپارچه: [ARCHITECTURE-fa.md](./ARCHITECTURE-fa.md)

## تصمیم معماری

این شاخه یک پوستهٔ بومی Win32 با وابستگی حداقلی به سیستم‌عامل ایجاد می‌کند. هدف سازگاری پوسته با Windows XP SP3 و نسخه‌های جدیدتر است؛ این هدف هنوز با ساخت و آزمون روی XP اثبات نشده است.

- پنجره و ورودی/خروجی پایه با Win32 API.
- نمایش پس‌زمینه فقط یک تصویر BMP ثابت اختیاری است؛ هیچ لایهٔ تزئینی، Canvas، WebGL، blur، parallax یا انیمیشن پس‌زمینه وجود ندارد.
- فهرست ماژول‌ها از `modules/modules.ini` خوانده می‌شود.
- نسل اول ABI ماژول‌ها به‌صورت DLL مورداعتماد در همان فرایند میزبان بارگذاری می‌شوند و یک HWND فرزند در فضای پنجرهٔ لانچر می‌سازند.
- هسته API نسخه‌دار کوچکی به ماژول می‌دهد؛ ماژول نباید به داده‌ها و حافظهٔ ماژول دیگر دسترسی مستقیم داشته باشد.
- ماژول‌های DLL در این نسخه sandbox واقعی ندارند. فقط کد مورداعتماد را بارگذاری کنید. جداسازی فرایندی و مجوزهای محدود، پیش‌نیاز انتشار عمومی‌اند.

## محدودیت حیاتی Windows XP

Windows XP به‌صورت رسمی به IE8 محدود است و موتورهای Chromium/Edge جدید روی آن اجرا نمی‌شوند. دموهای فعلی Generation 1 از JavaScript و Web APIهای مدرن استفاده می‌کنند؛ بنابراین نمایش مستقیم آن‌ها در WebBrowser کنترل IE8 قابل تضمین نیست. این پوسته به‌تنهایی سازگاری بازی‌های HTML فعلی را حل نمی‌کند.

برای اجرای واقعی بازی‌های Generation 1 داخل لانچر باید یک adapter مرورگری مستقل و نسخه‌بندی‌شده ساخته شود و قبل از انتخاب موتور، قابلیت‌های موردنیاز بازی‌ها (ES syntax، Canvas، WebGL، Fetch، Storage، Audio و امنیت TLS) روی هر سیستم سنجیده شوند. استفاده از Chromium/CEF منسوخ و ناامن صرفاً برای ادعای XP توصیه نمی‌شود. اگر XP الزام سخت باشد، یا باید مسیر بومی/ترجمه‌شدهٔ بازی‌ها تعریف شود یا پشتیبانی XP برای اجرای بازی‌های وب از ماتریس پشتیبانی جدا شود.

## ساختار

- `ui/index.html`, `ui/launcher.css`, `ui/launcher.js`: پیش‌نمایش رابط کاربری و نمونهٔ اجرای ماژول در قاب داخلی
- `BUILDING-fa.md`: دستور ساخت و آزمون

## پیش‌نمایش رابط کاربری

برای مشاهدهٔ نمونه، فایل `ui/index.html` را در یک مرورگر مدرن باز کنید. این بخش یک prototype وب مستقل است و هنوز به پوستهٔ Win32 متصل نشده است. دو ماژول نمونه و یک بازی کلیکی کوچک در قاب داخلی اجرا می‌شوند. کالیبراسیون فقط از اطلاعاتی استفاده می‌کند که مرورگر گزارش می‌دهد و نتیجهٔ آن تقریبی است؛ این اطلاعات جای سنجش واقعی CPU/GPU/RAM در نسخهٔ بومی را نمی‌گیرد. تنظیمات prototype در localStorage مرورگر ذخیره می‌شوند.
