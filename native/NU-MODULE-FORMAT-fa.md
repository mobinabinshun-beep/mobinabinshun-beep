# قرارداد ماژول N.U و VM نسل اول

وضعیت: پیاده‌سازی آزمایشی محدود در Native Shell

## هدف
لانچر نباید برای نمایش پوسته یا اجرای نمونهٔ ماژول به مرورگر نصب‌شدهٔ سیستم وابسته باشد. برای اثبات این اصل، میزبان Native یک قالب اعلانی محدود با نام NUVM/1 را می‌خواند و دستورهای مجاز آن را خودش تفسیر می‌کند.

## قالب نسخهٔ اول

فایل متنی UTF-8/ASCII با پسوند `.nup`:

```
NUVM/1
GENERATION=1
HOST_API=1
TITLE=Example module
TEXT=First line
TEXT=Second line
END
```

## محدودیت‌های امنیتی فعلی
- حداکثر اندازهٔ فایل: 16 KiB
- حداکثر طول هر خط: 191 بایت
- حداکثر 16 دستور TEXT
- فقط دستورهای شناخته‌شده پذیرفته می‌شوند.
- اجرای DLL/EXE، JavaScript، HTML، شبکه، دسترسی فایل، thread، shader و کد بومی وجود ندارد.
- نسل باید دقیقاً با نسل میزبان برابر باشد؛ HOST_API نباید از نسخهٔ میزبان بالاتر باشد.
- ماژول ناسازگار یا دارای opcode ناشناخته رد می‌شود.

## مرز ادعا
این VM فقط یک مفسر اعلانی اولیه برای اثبات مسیر «بسته ← اعتبارسنجی ← ترجمه/تفسیر ← نمایش Native» است. هنوز مترجم عمومی بین نسل‌ها، WASM، اجرای بازی‌های Generation 1 فعلی، sandbox سطح سیستم‌عامل، امضای بسته، dependency resolver یا Package Manager تولیدی نیست.

## مسیر توسعه
1. تثبیت manifest امضاشونده و schema نسخه‌دار.
2. تعریف opcodeهای خالص و بدون اثر جانبی.
3. جداسازی VM از UI و اعمال quota دستور/حافظه/زمان.
4. افزودن translatorهای مستقل به ازای هر نسل.
5. افزودن capability broker و permission policy.
6. افزودن تست‌های fuzz و conformance قبل از بازکردن هر API جدید.
