این صفحه فقط برای ارزیابی بصری است. پس از انتخاب، باید موبایل/دسکتاپ، کاهش حرکت، خوانایی UI، سرعت بارگذاری و پایداری فریم بررسی شود.

آنچه در مخازن پیدا شد

A · Material/Background.svg

مرجع تصویری اصلی در مخزن Repository؛ 2,767,594 بایت. مناسب‌ترین گزینه برای تست به‌عنوان پایه، اما محتوای SVG در API قابل استخراج نبود و باید در مرورگر بارگذاری شود.

B · Original reference PNG

فایل مرجع تصویری دیگر در مخزن دمو؛ 2,467,298 بایت. قابل تست به‌عنوان مقایسهٔ مستقل با SVG.

C · Generation 1 pixel renderer

شهر پیکسلی 480×270 با آسمان زمان‌محور، زمین، رودخانه، شهر، ترافیک و ذرات. کاملاً قابل تست؛ اما طبق Visual Bible جغرافیا و نقشهٔ آن پیشنهاد هنری است، نه مرجع قطعی کانن.

D · Generation 2 cosmic renderer

سیارهٔ بزرگ، حلقه‌های طلایی، ماه، رشته‌کوه، شهر و ارگ مرکزی. کد آن در مخزن Repository و صفحهٔ تست مستقل نسل دوم وجود دارد؛ اینجا فقط رندر پس‌زمینه جدا شده است.

E · CSS sky / horizon

گرادیان آسمان و افق قدیمی در nu-world.css و نسخه‌های پشتیبان. مناسب fallback سبک، نه تصویر مرجع نهایی.

Atmosphere overlay

nu-dynamic-layers.js: درخشش، پرتو و ذرات مستقل. این یک لایهٔ مکمل است، نه بک‌گراند پایه؛ باید فقط بعد از انتخاب پایه آزمایش شود.
